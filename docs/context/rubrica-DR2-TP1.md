## Competência 1. Operar o sistema operacional Linux utilizando a linha de comando

1. O aluno demonstrou que sabe justificar a importância do Linux em sistemas computacionais modernos?
2. O aluno demonstrou que sabe operar o terminal Linux executando comandos básicos corretamente?
3. O aluno demonstrou que sabe navegar pelo sistema de arquivos utilizando a linha de comando?
4. O aluno demonstrou que sabe visualizar e manipular arquivos e diretórios com precisão?
5. O aluno demonstrou que sabe utilizar comandos auxiliares para obter documentação e suporte?
6. O aluno demonstrou que sabe justificar decisões técnicas adotadas durante a execução das tarefas?
7. O aluno demonstrou que sabe organizar e documentar corretamente os artefatos produzidos?
